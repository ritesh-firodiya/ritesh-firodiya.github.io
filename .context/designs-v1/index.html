What was wrong — and it was not the wording

The previous design pass carried two studio-wide promises: "no ads in our games" and "one-time purchases, not subscriptions you forget about". Checked against the app repositories, both were false. Tic Tac Toe ships an AdMob banner and interstitial. Four of eight apps are subscriptions. A third page said Chitragupt was "free, and it stays free" while its own config defines ₹249 / ₹499 / ₹799 tiers. A fourth showed Imposter a working "Join the beta" button while its STATUS.md said "Neither store has a public release. Nothing is live."

These sat on the developer website linked from live store listings. The mistake was the shape of the claim: a promise on behalf of every app is only as true as the least convenient app, and it decays silently because the thing that breaks it is a change in a different repository.

The four rules this set adds

1 · The model is stated before the install button, always. Free+ads, one-time and subscription render at equal visual weight. A subscription is never softened into "unlock"; ads are never omitted. There is no "good" colour in the model palette.

2 · No studio-wide promise. Any claim not true of every app on the page is scoped to the apps it is true of, or cut.

3 · Availability is never a euphemism. A platform with nothing installable renders disabled with the reason — never hidden, and never a link that most people cannot open.

4 · A missing asset is visibly missing. Every image slot is a labelled placeholder naming what belongs there and at what size.

What is deliberately not here

The generator. Every fact on /products is meant to be produced by a script that reads the app repositories and refuses to build when a stated fact disagrees with source — so an app that gains an ad SDK breaks a deployment rather than a promise. That is the next phase, not this one.

Chrome stripping in the gallery sync. The live iframes on /design/[slug] currently render the development chrome that every design file carries while being worked on. The sync step must remove it. Visible on the page on purpose.

Real assets. Roughly 60 labelled placeholder slots. Most already exist in the app repos' store folders and can be copied rather than made.

The framework. No route, component or config has been touched. These are plain HTML and Tailwind on purpose, so they port to whatever the site is eventually built with — including a Next.js + Tailwind v4 rewrite, where the :root block in shared.css becomes the real theme almost verbatim.

The legal documents themselves. Only the index page is designed here; moving the 13 files and shimming the old URLs is an ops task with a hard gate on the in-flight Charades submission.
