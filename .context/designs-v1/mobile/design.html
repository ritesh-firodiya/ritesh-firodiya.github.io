The rules

Nine rules, none of them invented on purpose.

Found by reading nine design systems written months apart and noticing which arguments kept being made independently.

  1. 01

    One or two colours are reserved

    And nothing else may use them. If green can also mean "Food & Drink", the one colour carrying the game carries nothing.

  2. 02

    The wireframe is the spec

    When code and wireframe disagree, the wireframe wins. One project inverts this and writes the inversion down.

  3. 04

    A token with no variable has no utility

    The config holds only variables; the stylesheet holds the values. They cannot drift.

  4. 09

    Write down what was deleted, and why

    Three tokens referenced but never defined silently killed a shadow on 26 buttons, for months, with no error anywhere.
