The problem

Every Indian tax calculator answers one question — which regime is cheaper for you, one person, this year. That is the wrong unit. Tax in an Indian household moves across people, and filed one at a time a family leaves deductions on the table.

What it does

  • Parses a Form 16 upload into a structured return.
  • Old and new regime side by side, delta in rupees.
  • Household lens across spouse, parents and kids.
  • Prints the refund and the deductions still unused.

Decisions worth defending

Zod as the only contract

A schema shared by form, function and document means a budget rule change is one edit, with the type system finding the rest.

189 small functions

Each deduction is its own tested unit. A wrong number traces to one file — the only failure mode that matters here.

Result never paywalled

A tax tool that hides the number behind a payment has already lost the user's trust.
