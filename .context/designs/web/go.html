The short link · /go/<slug>

One link per app that a phone resolves to the right destination. It goes in a bio, a QR code or a forwarded message, so the link never has to be reprinted when a platform opens. It is a page rather than a bare redirect for three reasons: a wrong guess must be recoverable, a disabled platform must say why, and a desktop visitor needs something other than a store they cannot install from.
