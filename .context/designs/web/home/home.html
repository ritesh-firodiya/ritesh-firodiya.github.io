How I ship · powered by canon and zeno

Eight stages. Two tools. Every product shows where it is stuck.

canonKnowledge, shared Private for now

One site and one search over every product's wiki. Specs, decisions and runbooks start from the same templates, and every edit is a reviewed pull request.

zenoRules, enforced Open source

Each repo keeps its prices, rules and past decisions. The AI checks every request against them before it acts, and each stage waits at its gate.
