The problem

Every Indian tax calculator answers one question — which regime is cheaper for you, one person, this year. That is the wrong unit. Tax in an Indian household moves across people: a parent’s medical premium, a spouse’s home-loan interest, a child’s tuition.

Filed one at a time, a family routinely leaves a deduction on the table that was always claimable. The product is not filing. It is the review before filing.

The part worth telling

An earlier version of this portfolio called Chitragupt free, and it stays free while the product’s own config defined three priced tiers. That page was linked from live store listings.

The fix was not better wording. A promise made on behalf of a product is only as true as the least convenient fact about it, and it decays silently because the thing that breaks it lives in a different repository.

So every fact on this site now lives in one file, is stated per product, and carries the date a human last checked it against the source.

Drawn before built

264 screens as static HTML, reviewed before any product code shipped — every flow, and every empty, loading, error and locked state. A component that appears in no HTML file does not ship.

Those sets live in the product repository, which is where they are reviewed. They are deliberately not republished here.
