A pre-file tax review for salaried Indians: upload Form 16, AIS, 26AS and a bank statement, get the deductions a rushed CA misses.

The problem

A salaried filer in India hands a CA four documents and gets back a number. The deductions that get missed are the ones nobody asked about — a let-out property, an 80D premium paid for a parent, the HRA nobody claimed because the rent receipts were with a former flatmate.

The product is not tax filing. It is the review before filing: reconcile the four documents against each other, flag what disagrees, and hand a verified CA a shorter list.

The part worth telling

An earlier version of this portfolio described Chitragupt as “free, and it stays free” while the product’s own config defined three priced tiers. That page was linked from live store listings.

The fix was not better wording. A promise made on behalf of a product is only as true as the least convenient fact about it, and it decays silently because the thing that breaks it lives in a different repository. So every fact on this site now lives in one JSON file, is stated per product, and carries the date a human last checked it against the source.

The model is stated above the install button. Never below it, never in a footnote, never softened into “unlock”.

Designed before built

264 screens were drawn as static HTML and reviewed before a line of product code shipped — every flow, and every empty, loading, error and locked state. A component that appears in no HTML file does not ship.

Those sets live in the product repository, which is where they are reviewed. They are deliberately not republished here.
