# Wiki — schema and rules

This wiki follows the **zeno wiki schema**: page types, frontmatter, required
sections, ID conventions and lint rules. Read it before creating or editing any
page here — `zeno standards` lists it as `wiki-schema`, and the zeno plugin's
`/zeno:ingest`, `/zeno:ask`, `/zeno:decision` and `/zeno:wiki-lint` follow it.

Nothing in this site's wiki departs from the shared schema. A rule that only
applies here goes below this line, with the reason.
