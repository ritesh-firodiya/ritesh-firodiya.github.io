# canon

**The story is the product, not the code** (owner, 2026-10-23). canon is a productivity tool for the product lifecycle: domain knowledge kept local, then enforced. The page says that in the hero and never shows a file path or terminal output except the install lines.

**Five short sections**: the problem (AI forgets your domain) → how canon fixes it (Know, Enforce, Ship) → what it caught → across the lifecycle → one closing card. The principles list is a link, not a section.

**"What it caught" is domain mistakes**: a price plan, a shelved feature, the user's only data, a hosting move. Three are eval verdicts on a sample app and the page says so; one is from the owner's products. Each card is the request as a quote, the verdict, two reasons and the sources.

**The lifecycle strip** carries what used to be the Process board on Home: eight stages, each with what canon keeps there.
