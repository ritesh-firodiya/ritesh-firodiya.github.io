## Why it is drawn this way
**It is its own screen, not a state of Project.** Nothing in the closed set of states names "not shipped", and the page is laid out differently: there is no install row, no screenshot and no case study.

**It says what exists.** For a project in design that is a wiki and a design set. Listing them is what makes an unshipped project evidence rather than a claim.

**Every platform is drawn disabled with its reason.** The reader is never left to guess whether a button is missing or broken.

**A withheld design set is shown as withheld**, with the reasons the build recorded. DwarSeva Property's set fails the style guide, so it is not published and this card says why.

**No screenshot slot pretends.** It is hatched and labelled.

**Built differently from the wireframe (2026-10-04, review round 3).** It shares the flat project page; see [[project]]. The wireframe has not been redrawn yet.
