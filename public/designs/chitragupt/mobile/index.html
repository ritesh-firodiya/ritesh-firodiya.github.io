Design conventions

  • · Phone frame · 390 × 844 · centered on desktop with rounded corners + shadow
  • · Top bar: avatar (left → opens left drawer) · title · notifications (right). Detail pages swap avatar for back-arrow.
  • · Bottom tab bar: Inbox · Tax · Home (elevated, centered) · Expense · Portfolio
  • · Inbox default = folder tree (Tax / Bank / Investments / Health). Toggle to flat list. Search across all docs.
  • · Bottom sheets for modals (Razorpay paywall · categorise · budget · harvest · rebalance · confirm trade · map goal · destructive confirm).
  • · Family workspace tinted blue · Pro Family upgrade gates via payment/upgrade.html.
  • · Most variants use shared chrome via _chrome.js — older anchors keep inline chrome for portability.

Excluded from mobile

Marketing pages (landing/pricing/FAQ/legal), admin console, and CA portal — those stay web-only. Transactional email bodies live on the website wireframe set too.
