Workspace switcher

How a user moves between their own ledger, the combined family view, and per-member views. The dropdown above shows the open state of the top-right avatar.

Three ways to switch

  • 1

    Click the avatar (top-right)

    Fastest. Always-on, available on every authed page. The dropdown above is what opens.

  • 2

    From Settings → Workspaces

    A larger panel with more context per workspace (scope, permissions, last activity). Open Settings →

  • 3

    From the Family dashboard

    Each per-member tax card links into that member's view. Open dashboard →

What changes when you switch

  • The URL rescopes: /tax → /family//tax or /family/tax (combined)
  • The persistent "Viewing as name" indicator (top-right) updates to make whose ledger is on screen unmistakable
  • Data hooks (useAnalyze, useDocuments) read from the new uid · scoped Firestore rules enforce server-side
  • The Ask CA pill scope updates — questions asked here go against the active workspace's data

Key rules

  • Combined views (Expense + Portfolio) are computed live from each member's data — never duplicated
  • Tax filings stay per-PAN · the "combined" view stacks per-member positions, it doesn't merge them
  • Read-only members can be viewed but not modified · their data stays in their account
  • The CA role appears in the switcher only when the user has accepted a CA invite or is themselves a verified CA
