Why we need this

Owner-listed properties go live faster. Agent-listed properties need a signed NoC (No-Objection Certificate) from the owner + a valid RERA agent registration. This protects buyers from scam re-listings.

  • · Your name as authorised agent
  • · Owner signature + date (≤ 30 days)
