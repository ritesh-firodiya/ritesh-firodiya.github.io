Word packs

v5 — packs are multi-select. v4 made you pick exactly one, which is a decision nobody wants to make every round. imposter.app ships "Everyday Things +5"; Imposter Who? defaults to "All Categories". Picking several is the normal case, so Select all sits in the header.

Rule 3 — a locked pack is dimmed and labelled, never hidden. A pack nobody can see is a pack nobody buys, and hiding them makes seven tiles appear from nowhere the moment someone pays.

Tapping a locked tile opens the paywall rather than doing nothing. A tile that ignores a tap is a bug the user has to disprove.

Every tile prints words AND hints. The best review in the whole competitive set is about hint quality — "Word: Will Smith, Imposter Hint: Slap — it feels like humans put thought into this." Competitors advertise word counts; nobody advertises hints, because nobody writes them.

The counts are real. 749 pairs across ten packs, ~75 each. The registry, the tests, the UI and this wireframe all read the same number, so nothing anywhere advertises a total the app cannot back.

The plate is white with a line icon. Rule 1 owns the green and the black; a pack cannot borrow either, so the drawing carries the meaning instead.
