Almost nobody will see this. The app is fully offline — word packs are bundled TypeScript, not a fetch — so the only real loading is RevenueCat resolving prices on a cold start.

Which is exactly why the skeleton is on the pack grid and not a full-screen spinner: the rows are already known, only the lock state is not.

The CTA is never a spinner. Dealing cards needs no network, so it stays live even while prices are still resolving. An offline game that blocks its own start button on a price lookup is the worst kind of bug — invisible on a fast connection.
