Notification Permission

Purpose: Prime users for notification permissions with transparency about what they'll receive.

Key features:

  • Permission benefit explanation
  • Transparency about notification types
  • System prompt trigger on acceptance
  • Permanent opt-out acknowledgment

Why: Never ask iOS for push permission cold — one deny is a permanent loss. Prime first, promise what we'll send (and what we won't), then trigger the system prompt only if they say yes.
