Board — src/app/game.tsx

The board is the screen. Everything else — header, turn line, buttons — is sized so that none of it competes with a 64px glyph read at arm's length by the other player.

Geometry is not free-hand. 3 columns, 6px gap, 12px padding, 2px border, from src/constants/styles.ts. React Native boxes are border-box, so the border eats the width the cells share; leaving it out of the maths once made the row 4pt too wide and wrapped the third column.

Blue is X, rose is O, and nothing else may be either. The turn chip tints the same token at 16%, so the two are obviously the same colour rather than two blues that nearly match.

Reset, not New game. Mid-game the primary action clears the board and keeps the mode. It becomes "New game" only once the game is over — the same button, relabelled, because the intent genuinely changes.

Thinking is a state, not a spinner over everything. The board dims and the turn line says whose move it is; the player can still see the position while the AI moves.
